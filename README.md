# SIH_PROJECT — Civic Issue Reporter

Smart India Hackathon 2024 prototype: a web app for reporting civic issues. Citizens report local issues on a map, and admin and municipality dashboards track them.

- Pages: user UI, admin dashboard, municipality dashboard
- Stack: HTML + Tailwind CSS, Leaflet map, vanilla JavaScript
- Status: front-end prototype. The admin login is a hardcoded demo placeholder, not real authentication. There is no backend.

## How to run

No build step and no backend. Open the HTML pages directly in a browser.
